# Keyboard shortcuts

Disk Analyzer Free provides keyboard shortcuts for common window actions. The **Settings → Shortcuts** page shows the active shortcut for each action. Defaults that use a platform standard key sequence can differ between Windows, macOS, and Linux.

| Action | Default |
| --- | --- |
| New scan | `Ctrl+N` / `Cmd+N` |
| Refresh selection | `F5` |
| Focus query | `Ctrl+F` / `Cmd+F` |
| Copy path | `Ctrl+C` / `Cmd+C` |
| Delete to Trash | `Delete` |
| Delete permanently | `Shift+Delete` |
| Save snapshot | `Ctrl+S` / `Cmd+S` |
| Open snapshot | `Ctrl+O` / `Cmd+O` |
| Export | `Ctrl+E` / `Cmd+E` |
| Switch to tab 1–9 | `Ctrl+1` through `Ctrl+9` / `Cmd+1` through `Cmd+9` |
| Settings | Platform Preferences shortcut (usually `Ctrl+,` or `Cmd+,`) |
| Cancel scan | `Esc` while the scan progress panel has focus |
| Help | `F1` |

To change a shortcut, open **Settings**, select **Shortcuts**, and edit its key sequence. Changes are staged with the other preferences and take effect only after selecting **OK**. **Cancel** discards them. Use **Restore default shortcuts** to restore the defaults.

Two actions cannot share the same sequence, and one action cannot use a sequence that is the beginning of another action's multi-key sequence. The settings page reports these conflicts and will not save until they are resolved. Clear a shortcut to leave that action unassigned. If two stored bindings conflict, the application suppresses both until the conflict is fixed.

Actions that are not available yet are shown disabled. Their shortcuts can still be customized and saved for a later version.
