# Security Policy

## Supported versions

Security fixes are provided for the latest minor release. This project is under active development and does not yet publish releases.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/Ahmed41022/disk-analyzer-free/security/advisories/new) for sensitive reports. Do not include exploitable details in a public issue.

Reports will be acknowledged and triaged within seven days. If private vulnerability reporting is unavailable, contact the repository owner through GitHub before publishing details.

Include the affected version or commit, operating system, steps to reproduce, expected and observed behavior, and any relevant logs. Avoid attaching disk images or files containing personal data.
